# Tesla and GameStop Stock Analysis

This project analyzes historical stock prices and revenue data for Tesla and GameStop using Python.

### Tools & Libraries
- Python
- Pandas
- yfinance
- Requests & BeautifulSoup
- Matplotlib

### Key Tasks
- Extract historical stock data.
- Scrape company revenue data from web pages.
- Process and visualize stock prices and revenue.



### Purpose
Completed as part of the IBM Python project-based learning lab to practice data extraction, web scraping, and data visualization.
